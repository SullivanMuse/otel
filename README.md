# OpenTelemetry Demo

This repo contains example code for implementing OpenTelemetry for local development. The full_demo contains a full stack example with a frontend (TS/Lit), a backend (Rust), and a power supply controller (Python) and a simulator implementing a mock SCPI interface for a power supply.

You can start either example project by `cd <project>` and then running `docker compose up -d --build`.
